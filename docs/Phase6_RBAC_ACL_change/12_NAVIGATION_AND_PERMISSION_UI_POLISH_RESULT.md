# Phase 6.2.2 — Navigation and permission UI polish

The project-member picker now uses one autocomplete input with a selected-user chip and hidden `user_id`; server validation still rejects inactive, unknown, or already-active members. Sidebar business navigation is isolated to the current module, while authorized administration items and the module switch remain available. Role permissions are grouped into Phân hệ, Người dùng/Vai trò, Quản trị hệ thống, Dự án/Báo cáo, Hồ sơ dự án, Thư viện ảnh/video công ty, and Quản lý đối tác.

No ZIP download, storage namespace work, file-level ACL, or per-user global permissions was added.
